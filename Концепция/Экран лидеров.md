# Экран лидеров — UX-спека

Связано: [[Таблица лидеров]], [[UI — паттерны интерфейса]], [[Экран заданий]].

Спека написана ДО переделки экрана и служит для неё заданием. Реализация —
`scripts/leaderboard_screen.gd`, данные — `leaderboard_client.gd` (сервер) с
откатом на `leaderboard_mock.gd`.

## Зачем игрок сюда заходит

1. **Кто наверху** — посмотреть на первую тройку, это витрина.
2. **Где я** — и насколько близко следующая ступень.
3. **Что мне это даст** — какой приз за место и сколько до розыгрыша.

## Что было не так

| Проблема | Следствие |
|---|---|
| Строки полупрозрачные, сквозь них видна кирпичная стена | Текст дерётся с текстурой, награда справа почти нечитаема |
| Первая тройка отличается ТОЛЬКО цветом номера | Витрины нет вовсе; вопрос 1 не отвечен, дальтоник тройку не видит |
| Своей позиции на экране нет | Вопрос 2 требует нажать «МОЯ ПОЗИЦИЯ» и проскроллить |
| Кнопка «МОЯ ПОЗИЦИЯ» висит поверх списка | Закрывает строки и выглядит приклеенной |
| Вкладки — плоские полосы, активная чуть светлее | Какая выбрана, понятно только по оттенку |
| Вкладок было две, и обе про бесконечный | «Гора пицц» мерила усидчивость, а не игру; таблиц теперь четыре — по одной на режим, см. [[Таблица лидеров]] |
| Приз набран текстом «+5000 $», доллар — буквой | Расходится с остальной игрой, где валюта это спрайт |
| Таймер розыгрыша — мелкая подпись под заголовком | Главный мотиватор подан как сноска |
| Список упирается в края экрана, последняя строка обрезана | Не видно, что список продолжается |

## Раскладка

```
┌──────────────────────────────────────────────────────────────┐
│ ←   ЛИДЕРЫ            [ПРИЗЫ ЧЕРЕЗ 3д 14ч]      1024$   83⊙  │  шапка
│   (ЭПИЗОД 1) (эпизод 2) (🔒эпизод 3) (🔒бесконечный)  ?      │  вкладки
├──────────────────────────────────────────────────────────────┤
│    ╔════════╗   ╔══════════╗   ╔════════╗                    │
│    ║ ② имя  ║   ║ ① имя    ║   ║ ③ имя  ║                    │  подиум
│    ║ 407🍕  ║   ║ 412🍕    ║   ║ 402🍕  ║                    │
│    ║ 2500💲 ║   ║ 5000💲   ║   ║ 2500💲 ║                    │
│    ╚════════╝   ╚══════════╝   ╚════════╝                    │
├──────────────────────────────────────────────────────────────┤
│  4  ▸ имя            400 🍕              +1000💲 +2⊙          │  список
│  5  ▸ имя            394 🍕              +1000💲 +2⊙          │  с 4-го
├──────────────────────────────────────────────────────────────┤
│  ТЫ  47  Normaldo    123 🍕        [ ПОКАЗАТЬ В СПИСКЕ ]      │  моя строка
└──────────────────────────────────────────────────────────────┘
```

**Подиум** — три карточки над списком; первое место шире и выше, стоит по
центру. Медальон с номером ① ② ③, аватар, имя, счёт, приз.

**Список** начинается с 4-го места: первые три уже показаны подиумом, дублировать
их нечем.

**Моя строка закреплена внизу** и видна всегда — на вопрос «где я» экран
отвечает сразу, без нажатий. Тап по ней прокручивает список к своей строке
(бывшая кнопка «МОЯ ПОЗИЦИЯ»).

## Доступность

1. **Место не передаётся одним лишь цветом.** Номер стоит цифрой в медальоне;
   своя строка помечена словом «ТЫ» и полосой-акцентом слева, а не только
   зелёным фоном.
2. **Активная вкладка отличается формой**: залитая пилюля с тёмным текстом
   против контурной с тусклым, а не оттенком фона. Закрытая помечена
   нарисованным замком: тусклостью её не отличить — неактивная тоже тусклая.
3. **Подложки строк непрозрачные** — фон не просвечивает, контраст текста не
   ниже 4.5:1.

## Откуда данные

Источник ровно один — **сервер**. Своих строк у экрана нет.

Раньше был второй: пока сервер молчал (нет сети, не поднялась авторизация, или
просто до ответа), экран подставлял **двести выдуманных игроков** с выдуманными
очками, выдуманное «31 место из 1247» и выдуманный отсчёт «призы через 3 д
14 ч». Пометки не было никакой — отличить вымысел от настоящей таблицы игрок не
мог ничем. Это худшее место для вымысла: вся ценность таблицы в том, что число в
ней настоящее.

Теперь:

- **нет ответа** — экран так и говорит: «Таблица не пришла… результат забега уже
  засчитан». Строк нет;
- **места нет** — вместо числа прочерк, и на экране смерти тоже. Кнопка
  «показать в списке» при этом прячется: предлагать прыжок в список, которого
  нет, значит обещать то, чего никто не выполнит;
- **сколько всего игроков** — только `total_players` из ответа сервера;
- **отсчёт до сброса** — считается по календарю до ближайшего понедельника
  00:00 UTC, потому что по ISO-неделям сервер и раскладывает таблицы.

Файл `leaderboard_mock.gd` стал `leaderboard_modes.gd`: в нём остались перечень
режимов и лестница призов — то, что данными не является.

Единственная оставшаяся выдумка — **дев-кнопка приза**: она показывает окно
выигрыша на выдуманном месте, чтобы посмотреть вёрстку, не выигрывая неделю
по-настоящему. Она живёт только в дев-сборке и о себе честна.

## Проверка

`dev/smoke_leaders.gd`: на полосе ровно четыре вкладки по режимам, каждая
открывается ровно со своим режимом (эпизод 1 — всегда, эпизод N — после N−1,
бесконечный — после всей кампании), нажатие по закрытой не переключает, а
показывает подсказку; подиум показывает ровно первую тройку, список начинается
с 4-го места, своя строка есть всегда и её номер совпадает с данными,
переключение вкладок перестраивает список, экран освобождается при закрытии.
Кадр снимает `dev/shot_leaders.gd`.
