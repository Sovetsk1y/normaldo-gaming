# Карточка скина — UX-спека

Связано: [[Скины]], [[Экран скинов]], [[UI — паттерны интерфейса]].

Спека написана ДО переделки и служит для неё заданием. Реализация —
`hud._show_skin_detail()`.

## Зачем игрок сюда заходит

1. **Что этот скин умеет** — резисты, пассивка, активная способность.
2. **Насколько он прокачан** и сколько до следующего уровня.
3. **Что дадут дальше** — награды за уровни.
4. Надеть или купить.

## Что было не так

| Проблема | Следствие |
|---|---|
| Способности показаны ДВАЖДЫ: кружками по центру и списком слева | Половина центральной колонки занята дублем |
| Левая колонка не влезает: текст обрезан по нижнему краю панели | Последняя способность читается наполовину |
| Панели — плоские прямоугольники впритык к краям экрана | Экран выглядит как таблица, а не как карточка героя |
| Полоса опыта подписана «ур.4 … ур.5» | Сколько осталось до уровня — не сказано |
| Колонка наград обрезает карточки сверху и снизу | Непонятно, где начало списка |
| Подсказка «нажми на блок СПОСОБНОСТИ» | Осталась от версии, где описание не заполнялось сразу |

## Раскладка

```

│ ←        ГАРРИ  (ЛЕГЕНДАРНЫЙ)                   12400$  83⊙  │
├────────────────┬─────────────────┬───────────────────────────┤
│ СПОСОБНОСТИ    │   ПРОКАЧКА      │  НАГРАДЫ ЗА УРОВЕНЬ       │
│                │                 │                           │
│ (o) РЕЗИСТ     │    портрет      │  ┌─────────────┐ lvl.5    │
│     откат 8 с  │    + кормёжка   │  │ ⊙x2   💲x100│          │
│     змея       │                 │  └─────────────┘          │
│ (🔒) РЕЗИСТ 6  │  ур.4 ▓▓▓░ ур.5 │  ┌─────────────┐ lvl.6    │

│ (✦) АКТИВНАЯ   │                 │  └─────────────┘          │
│     вспышка    │  [  АКТИВЕН  ]  │                           │
└────────────────┴─────────────────┴───────────────────────────┘
```

**Способности живут только слева.** Ряд кружков из центра убран — он повторял
тот же список, отнимая место у прокачки. Кружок остаётся в строке списка.

**Центр отвечает за прокачку**: портрет с кормёжкой, подпись героя, лестница
состояний жира, полоса опыта **с числом** («ещё N пицц до ур.5») и кнопка
действия.

### Чем заполнена середина колонки

Между портретом и полосой опыта пустовала половина панели. Заполняют её два
блока, и оба по делу:

1. **Подпись героя** — одна строка в голос игры («Карту потерял. Пиццу нашёл.»).
   Скины коллекционные, и без подписи это просто головы в шапках. Тексты лежат
   в `SkinRegistry.LORE`, держатся в пределах ~90 символов — дальше не влезает
   в колонку. Тон правится свободно, это черновик.
2. **Лестница состояний жира** — четыре портрета, закрытые с замком и уровнем
   открытия. Это ровно то, о чём колонка: до сих пор о состояниях говорил
   только перетаскиваемый кусок пиццы, о котором игрок не догадывался, а какие
   состояния ещё закрыты — не говорил никто.

Лор специально НЕ вынесен в отдельную панель: он подпись под портретом, а не
раздел. Отдельная панель под две строки текста снова разредила бы экран.

**Все три колонки — скруглённые панели** с полями от краёв экрана и заголовком.
Содержимое, которое не влезает, прокручивается внутри своей панели, а не
обрезается по границе.

## Доступность

1. Закрытая способность — замок И подпись «откроется на N уровне», а не только
   приглушение.
2. Заголовки колонок словами, контраст описаний не ниже 0.80 белого.
3. Ничего не обрезается по краю панели: если не влезло — скролл.

## Проверка

`dev/smoke_skin_card.gd`: карточка собирается для всех скинов и всех состояний
(куплен / активен / не куплен), колонки не наезжают друг на друга и не выходят
за экран, способности перечислены ровно один раз, у закрытых стоит уровень
открытия, полоса опыта показывает остаток числом, кнопка действия соответствует
состоянию. Кадр снимает `dev/shot_skins.gd` с третьим аргументом — id скина.
