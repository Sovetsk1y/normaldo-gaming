# UI — паттерны интерфейса

Общий словарь для всех экранов. Заведён потому, что интерфейс собирается кодом,
и каждая новая панель до сих пор рисовалась заново: скругления, отступы и
тайминги нажатия у экрана скинов, наград и заданий разъезжались, хотя выглядеть
должны одинаково.

Правило простое: **делаешь новый экран — сначала ищи кирпич здесь.** Нет
подходящего — добавь его сюда вместе с кодом.

## Кирпичи

| Кирпич | Где код | Что это |
|---|---|---|
| Скруглённая панель | **`UiKit.rounded()` / `UiKit.panel()`** (`scripts/ui_kit.gd`) | Подложка с радиусом и рамкой. 12 — карточка, 10 — пилюля, 8 — кнопка и чип, 6 — полоса |
| Кнопка действия | `quests_screen._claim_button()` | Панель + подпись + невидимый `Button` сверху, с усадкой при нажатии |
| Усадка при нажатии | `_press_anim()` (есть в HUD и на экране заданий) | ×0.90 за 0.07 c, обратно за столько же. Один тайминг на всю игру |
| Чип | `quests_screen._build_reset_chip()`, шапка лидеров | Маленькая скруглённая плашка с текстом: таймер, счётчик, статус |
| Полоса прогресса | `quests_screen._build_progress_bar()` | Тёмный жёлоб + заливка цветом сущности + числа ПОВЕРХ полосы |
| Иконка + число | `_make_icon()` + подпись справа | Валюта всегда спрайтом, никогда текстом «100 $» |
| Кружок способности | `hud._ability_badge()` | Иконка в цветном кольце, с замком если закрыто |
| Медальон с номером | `quests_screen._build_tier_badge()`, подиум лидеров | Кружок с цифрой + слово рядом. Кодирует уровень дважды |
| Вкладки-пилюли | `leaderboard_screen._set_tab_style()` | Активная — залитая пилюля с тёмным текстом, неактивная — контурная с тусклым |
| Подиум | `leaderboard_screen._build_podium()` | Первая тройка карточками: центральная шире и выше боковых |
| Закреплённая своя строка | `leaderboard_screen._build_my_strip()` | Полоса внизу экрана: «ты такой-то», тап — прыжок к себе в списке |
| Перелёт награды | `quests_screen._fly_icons_to()`, `minigame_payout._fly_to_hud()` | Иконки летят в счётчик HUD, счётчик щёлкает по прилёту |
| Въезд экрана | `quests_screen` `SLIDE_TIME`/`SLIDE_TRANS` | «Проезд камеры»: экран приезжает снизу, меню уезжает вверх, одним таймингом |

## Правила

**Состояние никогда не передаётся одним лишь цветом.** У каждого состояния есть
слово, а часто и значок: `ЗАБРАТЬ` / `ИДЁТ` / `✓ ЗАБРАНО`, уровень сложности —
цифра в медальоне плюс `ЛЁГКОЕ`/`СРЕДНЕЕ`/`ТЯЖЁЛОЕ`, закрытый резист — замок
поверх кружка. Цвет только усиливает то, что уже сказано словом.

**Контраст текста на подложке не ниже 4.5:1.** Заголовки — почти белые,
пояснения не тусклее 0.80 белого. Подпись цветом сущности (золото награды,
зелень выполненного) допустима только на крупном кегле.

**Валюта — спрайтом.** `TEX_DOLLAR`, `TEX_TOKEN`, `TEX_MONEYBAG`. Текст «+100 $»
внутри игрового экрана читается как заглушка.

**Ничего важного за скроллом.** Экраны альбомные (960×430) — если контент не
влезает, сначала попробуй разложить в ряд, и только потом заводи скролл.

**Движется ровно один элемент.** Пульсирует то единственное, к чему игрок должен
подойти: готовая к получению карточка, доступный уровень. Два пульсирующих
элемента на экране гасят друг друга.
