# Концепция игры — Normaldo

Normaldo — мобильная аркада, в которой голова черепашки-ниндзя летит сквозь поток предметов. Игрок управляет её траекторией, уворачиваясь от препятствий и поглощая пиццу.

## Суть игры

> Ты летишь. Ты не просто двигаешь головой — ты управляешь её инерцией.

Ключевое отличие от предыдущей механики: голова больше не телепортируется к пальцу. Она тянется к нему через [[Принцип инерции (резинки)]] — с задержкой, массой, ощущением полёта.

## Core Loop

```
Нажал → голова тянется → объект съеден или уворот → очки/жир → управление меняется
```

1. Из правого края экрана летят [[Паттерны препятствий|объекты и паттерны]]
2. Игрок двигает пальцем — голова следует с [[Принцип инерции (резинки)|инерцией]]
3. Поглощение пиццы → [[Система толщины|жир накапливается]]
4. Жир делает голову тяжелее → lerp-коэффициент падает
5. [[Прогрессия сложности]] нарастает через паттерны, а не через скорость

## Платформа и управление

Мобайл. Одно касание. Работает одним пальцем, не требует точности позиционирования — требует **предсказания траектории**.

## Ключевой вызов дизайна

Старая механика ("палец = позиция") давала нулевой skill gap: игрок мгновенно учился обходить любые препятствия. Новая механика ("палец = цель, голова = масса") создаёт постоянно растущий skill ceiling без ускорения объектов до абсурда.
