# Экран заданий — UX-спека

Связано: [[Задания]], [[Экономика]], [[UI — паттерны интерфейса]].

Спека написана ДО переделки экрана и является для неё заданием. Реализация —
`scripts/quests_screen.gd`, данные — `scripts/quest_manager.gd`.

## Зачем игрок сюда заходит

Три вопроса, и ответить на них экран обязан **за две секунды, без чтения**:

1. **Что можно забрать прямо сейчас?**
2. **Что почти сделано?** — ради чего идти в следующий забег.
3. **Когда появится новое?** — если всё забрано.

## Что было не так

| Проблема | Следствие |
|---|---|
| Все карточки — одинаковые тёмные прямоугольники | Готовое к получению не выделяется; вопрос 1 требует чтения |
| Прогресс только текстом «0 / 1000 пицц» | Вопрос 2 не читается взглядом; нечем зацепиться |
| Сложность закодирована ТОЛЬКО цветом полоски | Дальтоник не различает уровни вовсе |
| Награда набрана текстом «+100 $» | Расходится со всей остальной игрой, где валюта — иконки |
| Список скроллится, третья карточка обрезана | Часть заданий не видна, подсказки о скролле нет |
| Экран 960×430 — альбомный, а список вертикальный | Половина ширины пустует, при этом контент не влезает |
| `_time_to_midnight()` посчитан, но нигде не показан | Вопрос 3 без ответа |

## Раскладка

Экран альбомный, поэтому три задания стоят **в ряд, а не в столбик** — влезают
целиком, скролл не нужен вовсе.

```
┌──────────────────────────────────────────────────────────────┐
│ ←   ЗАДАНИЯ            [до сброса 07:41]        1024$   83⊙  │  шапка
├──────────────────────────────────────────────────────────────┤
│  БОНУС ЗА ВХОД  +50 $                          [ ЗАБРАТЬ ]   │  баннер
├──────────────┬──────────────┬────────────────────────────────┤
│  ①  ЛЁГКОЕ   │  ②  СРЕДНЕЕ  │  ③  ТЯЖЁЛОЕ                    │
```

## Состояния карточки

Три состояния, и каждое различается **формой, значком и словом** — не только
цветом (см. «Доступность»):

| Состояние | Признаки |
|---|---|
| **Готово** | Золотая рамка + пульсация, кнопка **ЗАБРАТЬ**, полоса заполнена |
| **В процессе** | Обычная рамка, полоса прогресса с числами, подпись «идёт» |
| **Забрано** | Карточка приглушена, галочка **✓ ЗАБРАНО**, вместо полосы — таймер до нового задания |

## Доступность

Взято из чек-листа `team-ui` (репозиторий Claude-Code-Game-Studios, MIT):

1. **Состояние никогда не передаётся одним лишь цветом.** Сложность — номер
   ① ② ③ плюс слово; готовность — кнопка со словом; забранное — галочка.
2. **Контраст текста на карточке не ниже 4.5:1.** Тёмная подложка, почти белый
   заголовок; описание не тусклее 0.80 белого.
3. **Ничего важного не прячется за скроллом** — в этом и смысл раскладки в ряд.

## Проверка

Раздел «Экран заданий» в `dev/smoke_quests.gd`: экран собирается на всех трёх
состояниях карточки, кнопка «ЗАБРАТЬ» реально начисляет награду и переводит
слот на откат, таймеры тикают, повторный тап по кнопке ничего не начисляет
дважды. Кадр снимает `dev/shot_quests.gd`.
