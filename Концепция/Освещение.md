# Освещение

Normaldo — карикатурная аркада. Полноценный PBR-рендер здесь излишен и вреден: он съедает производительность на мобильных и может ухудшить читаемость игровых объектов. Цель — **атмосферное освещение без потери игровой ясности**.

## Принцип разделения слоёв

Ключевое архитектурное решение: **фон светится, геймплейные объекты — нет**.

В Godot 4 это реализуется через `light_mask` у CanvasItem и `item_cull_mask` у Light2D:

| Слой | light_mask | Освещается |
|------|-----------|-----------|
| Фон (BgA, BgB) | 1 | Да — Light2D с mask=1 |
| Препятствия, пицца | 2 | Нет |
| Нормальдо | 2 | Нет |

Это позволяет иметь живой световой фон, не затрагивая читаемость пицц и бочек.

## Инструменты атмосферы

### CanvasModulate — глобальный тинт уровня
Самый дешёвый способ задать настроение. Один нод на сцену.

```gdscript
# Переход между уровнями — плавная смена тинта
var tween := create_tween()
tween.tween_property($CanvasModulate, "color", next_level_color, 2.0)
```

Предлагаемая палитра по уровням:

| Уровень | Место | Тинт |
|---------|-------|------|
| 1 | Улица, день | `Color(1.0, 1.0, 1.0)` — нейтральный |
| 2 | Закат | `Color(1.0, 0.85, 0.65)` — тёплый золотой |
| 3 | Ночной клуб | `Color(0.4, 0.2, 0.6)` — тёмный фиолетовый |
| 4 | Канализация | `Color(0.5, 0.7, 0.4)` — зелёный смог |
| 5 | Босс | `Color(0.8, 0.2, 0.15)` — красная тревога |

### Light2D на фоне — декоративные источники
Фонари, вывески, окна. Всё с `Blend Mode: Add`, `item_cull_mask = 1` (только фон).
Анимировать через `energy` для мерцания неона.

```
Background/
├── BgA (Sprite2D, light_mask=1)
├── BgB (Sprite2D, light_mask=1)
├── StreetLamp1 (PointLight2D, item_cull_mask=1, blend=Add)
└── NeonSign (PointLight2D, item_cull_mask=1, blend=Add)
```

### Тень под Нормальдо
Не динамическая тень, а запечённый спрайт — размытый тёмный эллипс, `z_index` ниже Нормальдо. Даёт ощущение «приземлённости» в воздухе без нагрузки.

```gdscript
# Shadow (Sprite2D) — дочерний нод Normaldo
# modulate = Color(0, 0, 0, 0.25), y_offset = +36
```

## Освещение в боссфайтах

Боссфайт = драматическая смена атмосферы. Реализация:

1. **CanvasModulate** резко темнеет: `Color(0.15, 0.05, 0.05)` — ощущение арены
2. Босс имеет собственный **PointLight2D** с пульсацией `energy` в такт атакам
3. После победы — быстрый фейд обратно к нормальному тинту уровня

```gdscript
func _on_boss_started() -> void:
    var tween := create_tween()
    tween.tween_property($CanvasModulate, "color", Color(0.15, 0.05, 0.05), 1.0)
```

## Нарастающее затемнение как механика напряжения

По мере роста сложности (или приближения к боссу) тинт чуть темнеет. Игрок не замечает резко — но интуитивно чувствует тревогу.

```
Начало уровня: CanvasModulate.color.v = 1.0
Конец уровня:  CanvasModulate.color.v = 0.75
```

Это усиливает [[Прогрессия сложности|ощущение нарастания]] без изменения скорости спавна.

## Что НЕ стоит делать

- **Динамическое освещение на пицце и препятствиях** — лишает игрока мгновенной читаемости. Пицца должна быть видна всегда.
- **Тени от Light2D на геймплейном слое** — могут маскировать препятствия.
- **Мерцание глобального освещения** — вызывает раздражение при долгой сессии.
- **Полная темнота** — в мобильной аркаде недопустима, даже в боссфайте.

## Производительность на мобильных

- Максимум 2–3 активных Light2D в кадре. Фоновые источники отключать, когда уходят за пределы viewport.
- Prefer `CanvasModulate` над Light2D — нулевая нагрузка.
- Анимировать `energy` у Light2D, а не `color` — дешевле.
