# Бесконечный режим

Бесконечный — это **вся цепочка уровней подряд, по кругу**: канализация с ногой
ниндзя, улица с крокодилом, двор перед клубом с хозяином клуба, и снова
канализация. Играется до смерти; результат идёт в свою таблицу лидеров.

Открывается **после прохождения всех трёх эпизодов** (`SaveData.episodes_done ==
3`). Эпизоды — это та же цепочка, разобранная на отдельные забеги: прошёл
первый — забег кончился, открылся второй. Бесконечный собирает её обратно и
снимает конец.

Источник правды — `spawner.gd`: `campaign_mode = true`, `endless_chain = true`.

## Круг не откатывает сложность

После третьего босса цепочка заходит на первый уровень, но **не становится
легче**:

- скорость предметов растёт по общему времени забега и упирается в
  `CAMPAIGN_SPEED_MAX` — она к началу второго круга уже на потолке;
- фаза не опускается ниже уже достигнутой (`_phase_floor` в спавнере), поэтому
  канализация на втором круге идёт с той плотностью, на которой кончился двор
  перед клубом.

Без этого «бесконечный» превратился бы в «повторяющийся»: игрок доходил бы до
конца круга и получал передышку ровно в тот момент, когда ему должно было
становиться труднее.

## Боссы внутри бесконечного

Бой в бесконечном — не конец забега, а шов: за победой идёт карточка следующего
уровня, и забег продолжается ТЕМ ЖЕ забегом — жир, доллары и счётчик пиццы
переходят дальше. Выйти из бесконечного можно только смертью.

# Отправлено в запас: фазы и Безумие

**Ниже — прошлая версия режима.** Бесконечный был отдельной машинерией: своя
таблица фаз `ENDLESS_PHASES`, серия «Безумие» с накопительными модификаторами,
свой генератор паттернов, calm-wave между фазами. Уровней, боссов и букв в нём
не было вовсе.

Код этой машинерии всё ещё лежит в `spawner.gd`, но **больше недостижим**:
бесконечный теперь идёт через `campaign_mode`. Удалять его не стали — это
спроектированная система, и решение о её судьбе за автором. Если она не
возвращается, из спавнера уходят `ENDLESS_PHASES`, `_advance_endless_phase`,
`_endless_mods`, `_run_endless_pattern` и calm-wave.

## Структура (10 фаз)

### Crescendo (0–7 мин) — повторяет кривую кампании

| # | Имя | Длина | Скорость | Веса (T1/T2/T3/T45) |
|---|-----|-------|----------|---------------------|
| 0 | Разогрев   | 60 с  | 220 px/s | 7 / 3 / 0 / 0  |
| 1 | Поток      | 80 с  | 242 px/s | 2 / 5 / 3 / 0  |
| 2 | Натиск     | 90 с  | 264 px/s | 0 / 2 / 4 / 4  |
| 3 | Шторм      | 90 с  | 297 px/s | 0 / 1 / 3 / 6  |
| 4 | Ад         | 100 с | 330 px/s | 0 / 0 / 2 / 8  |

Сумма = 420 с = 7 мин. Те же значения скоростей, что в кампании, но без pre-boss фазы.

### Безумие (7+ мин) — нарастающие модификаторы

| # | Имя | Длина | Скорость | Веса | Модификаторы |
|---|-----|-------|----------|------|--------------|
| 5 | Безумие I   | 90 с | 350 px/s | 0 / 0 / 1 / 9  | `no_t1` |
| 6 | Безумие II  | 90 с | 370 px/s | 0 / 0 / 1 / 9  | + `trash_only`, `short_gap` |
| 7 | Безумие III | 90 с | 390 px/s | 0 / 0 / 0 / 10 | + `molotov_plus` |
| 8 | Безумие IV  | 90 с | 410 px/s | 0 / 0 / 0 / 10 | + `twin_pat` |
| 9 | Безумие V   | ∞    | 420 px/s | 0 / 0 / 0 / 10 | все модификаторы |

Каждая Безумие-фаза начинается с **calm-wave** — короткой ресурсной линии (см. ниже).

---

## Модификаторы

### `no_t1`
Веса T1 принудительно обнуляются при выборе паттерна. Никаких сэндвич-линий и каскадов — только T2/T3/T4/T5. Это срезает основной источник свободных пицц.

### `trash_only`
В любых T1 паттернах (если вдруг сработают) негативные предметы — всегда мусорные баки (урон 1), а не бананы. Дублирует поведение `_t1_pattern_count > 5`, но активирует с любого первого вызова в фазе.

### `short_gap`
Пост-паттерн пауза умножается на 0.7. Меньше передышек между атаками — давление выше.

### `molotov_plus`
Каждый молотов выстреливает `fire_count + 1` (было 4 → станет 5). Огневая зона дольше блокирует дорожку.

### `twin_pat`
После завершения паттерна с шансом 35 % сразу запускается ещё один паттерн **без пауз и бонусного предмета**. Twin не рекурсивен — двойной паттерн возможен, тройной нет.

---

## Calm-wave (передышка между Безумие-фазами)

При входе в фазу с индексом ≥ 5 спавнер запускает короткое окно облегчения:

1. `_frozen = true` — новые паттерны не запускаются.
2. 7 пицц на центральной дорожке (д3), интервал = `col_gap × 1.1`.
3. Ждём 4 секунды после последней пиццы.
4. `_frozen = false`, `_spawn_timer = 0.4` → возобновление нормального цикла.

Цели calm-wave:
- **Визуальный маркер** — игрок видит "что-то поменялось", запоминает рубеж
- **Восстановление жира** — шанс собрать пицц без давления (см. [[Система толщины]])
- **Дыхание после смены модификатора** — даём 5–6 секунд на адаптацию

В Crescendo-фазах (0–4) calm-wave **не запускается** — переход бесшовный.

## HUD: тосты фазы

При входе в каждую фазу спавнер эмитит сигнал `phase_entered(phase_idx)`. HUD ловит его и показывает центрированный тост (1.8 с) с названием фазы:

- Фазы 0–4 (Crescendo): зелёная рамка, светло-жёлтый текст
- Фазы 5–9 (Безумие): красная рамка, красно-оранжевый текст

Фаза 0 ("Разогрев") эмитится при старте через `call_deferred` в `hud._start_game()`, чтобы игрок видел название с первой секунды.

## Главный цикл (каждый кадр)

```
_phase_elapsed += delta

если _pattern_running == false
   и _frozen == false
   и _spawn_timer <= 0:
      _pattern_running = true
      запустить _run_endless_pattern()  [async]

если _phase_elapsed >= ENDLESS_PHASES[_phase]["duration"]:
      _advance_endless_phase()
```

### `_advance_endless_phase()`

```
_phase += 1
_phase_elapsed = 0
если _phase >= 10: _phase = 9   (фиксируем на Безумие V)
_endless_mods = ENDLESS_PHASES[_phase]["mods"].duplicate()
emit phase_entered(_phase)

если _phase >= 5: _run_calm_wave()
иначе: _spawn_timer = 0.8
```

---

## Цикл одного паттерна

```
1. _endless_pick_pat_tier() → tier 0..3
   (если no_t1 активен — вес T1 = 0)
2. _dispatch_pat(tier, ...) [await]
3. await 0.2 с
4. randf() < BONUS_CHANCES[tier] → _spawn_bonus_item(...)
5. если allow_twin и twin_pat и randf() < 0.35:
       _run_endless_pattern(allow_twin = false)
       return
6. gap = POST_PAT_GAPS[tier]
   если short_gap: gap *= 0.7
   await gap
7. _pattern_running = false
```

## Дизайн-цели

- **Игрок дальше 7 мин не упирается в потолок** — после Ада появляются новые слои сложности
- **Скорость не растёт бесконечно** — потолок 420 px/s сохраняет читаемость
- **Каждая фаза узнаваема** — имя + цвет тоста + (в Безумии) calm-wave-маркер
- **Прогрессия чувствуется** — модификаторы стэкаются, игрок видит "стало ещё жёстче"
- **Награда за выживание** — calm-wave восстанавливает жир и даёт момент перевести дух
