# Бэклог предметов

Предметы, разработанные для будущих уровней. Здесь хранятся механики, спрайты и звуки — чтобы не потерять при проектировании следующих уровней.

---

## Песочные часы

**Уровень:** планируется позже (возможно уровень 2–3)

| Параметр | Значение |
|---|---|
| Спрайт | `hourglass.png` |
| Анимация | бесконечное вращение (speed 5) |
| Звук | `magic_sound_longer.mp3` |
| Механика | Замедляет ВСЕ объекты на 4–6 сек. «Передышка» — паттерны становятся медленными, у игрока появляется время перестроиться |
| Категория | Нейтральный / усиление (SlowMoItem) |

**Почему не в канализации:** Механика «замедления мира» слишком сильна для первого уровня — игрок ещё не успел ощутить угрозу паттернов, которую часы снимают. Лучше работает там, где скорость объектов уже ощутимо давит.

## Телевизор

**Уровень:** планируется позже

| Параметр | Значение |
|---|---|
| Спрайт | `Sprite-0001TV2 4.png` |
| Анимация | нет |
| Звук | нет |
| Механика | Очищает весь экран от предметов. Побочный эффект — не определён, намеренно загадочный |
| Категория | Нейтральный (CleanScreenItem + CustomEffectItem) |

**Почему не в канализации:** Тематически не вписывается в сewer-эстетику. Требует отдельного осмысления побочного эффекта перед добавлением в уровень.

## Полицейский

**Уровень:** планируется для улицы / городского уровня

| Параметр | Значение |
|---|---|
| Спрайт | `policeman.png` (обычный) / `policeman_calling.png` (вызов подмоги) |
| Анимация | поднимает руку «вызывает подмогу» (scale 0→1) |
| Звук | `BRACERS.mp3` |
| Механика | Урон 1 + после попадания выбрасывает **Наручники**. Наручники при попадании — **мгновенная смерть** |
| Категория | Плохой (AttackingItem + спавнит KillingItem) |

**Наручники (связанный объект):**
- Спрайт: `jail 2.png`
- Анимация: scale-in, вращение (π×2 × 10 раз), движение к цели
- Механика: мгновенная смерть при попадании

**Почему не в канализации:** Полицейский логичен в городском контексте. Наручники с мгновенной смертью — слишком жёсткий штраф для уровня 1, где игрок ещё осваивает механику.
