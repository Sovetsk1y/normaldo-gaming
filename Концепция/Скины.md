# Скины

## Экран скинов (новый, 2026-06-30)

`hud.gd` → `_show_shop`: вместо горизонтального скролла больших карточек — **сетка
маленьких ячеек** (вертикальный скролл, `_build_skin_grid_cell`): картинка
state1, имя, редкость (названия на русском: Обычный/Редкий/Эпический/Легендарный),
**лейблы текущего/следующего уровня + XP-полоска** (трек `0.32,0.32,0.38` — как на
экране деталей), кнопка **НАДЕТЬ/КУПИТЬ/АКТИВЕН** (с увеличенным паддингом сверху;
`CELL_H` 132→156).
По тапу на ячейку **сетка уезжает влево, а справа въезжает детальный экран**
(`_show_skin_detail`, оба двигаются по X параллельно; назад — наоборот, и сетка
пересобирается, чтобы показать смену надетого скина). Фон `bg_skins.png`:

- **кнопка назад** (back_arrow, слева сверху) и **ресурсы** (доллар+токен, справа
  сверху) — **в точности как на других экранах** (масштаб от канваса 430×192,
  `_build_detail_resources`);
- **3 колонки:** слева «Описание» (способность/резисты/пассивка текстом), по центру
  **две раздельные суб-панели** (`_detail_panel`, паддинг 8 px между ними —
  служит разделителем): (1) **виджет кормёжки** (`_build_feed_widget`): аватар +
  палец-подсказка (back_arrow, ходит влево-вправо) + **перетаскиваемая пицца**,
  под спрайтом жира — **лейбл названия жира, отцентрованный ровно под спрайтом**,
  ниже — **XP-полоска** (лейблы уровней крупные, трек полоски осветлён, чтобы был
  виден на фоне). Зажал пиццу — рот открывается; провёл в Нормальдо и отпустил —
  звук еды + спин-морф к следующему жиру + звук (как в игре), до последнего жира.
  **Доступность жиров по уровню** (`_avail_max_fat`/`_fat_unlock_level`, зеркалят
  `normaldo._max_fat_state`: жир 2 — с ур.2, жир 3 — с ур.5): если скормить пиццу до
  жира, который ещё **не открыт** уровнем скина, спрайт показывается **полупрозрачным
  с замком** (`_lock_tex` — процедурный навесной замок; `_apply_fat_lock_visual`).
  **Тап по такому спрайту** (`_on_fat_lock_tapped`) → в «Описании» подробная подсказка
  (`_fill_desc_fat_lock`: новые жиры открываются прокачкой, этот — на ур.N; каждый жир
  = ещё один пропущенный удар), а справа список наград **плавно скроллится** к карточке
  этого уровня и она **мигает размером** (`_reward_focus_level`). На макс-жире вместо
  пиццы — кнопка `reset_fat.png` (сброс к первому жиру).
  (2) Блок **СПОСОБНОСТИ**: ряд круглых значков (`_ability_badge` — чёрный круг +
  тонкая цветная AA-обводка): **красная** = резист (внутри предмет), **синяя** = пассивка
  (★), **зелёная** = активный скилл (РЫГАЛИТИ — зелёное облако ноги ниндзя; спелл — ✦).
  **Тап по всему блоку** → в левой «Описание» (`_fill_desc`) появляются **строки
  «значок + текст»** на каждую способность (значок тот же кругляш); до тапа —
  подсказка. У каждой строки сверху **цветная пометка типа** — `РЕЗИСТ` (красный,
  заголовок строки = «Откат N c»), `ПАССИВНАЯ` (синий) или `АКТИВНАЯ` (зелёный —
  РЫГАЛИТИ/спелл). Кнопка
  **НАДЕТЬ** (или **КУПИТЬ {цена} + иконка доллара**, если не куплен),
  справа **«Награды за уровень»** (`_build_rewards_column`): заголовок в 2
  строки + **скроллящийся клиппящийся** список карточек (`ScrollContainer`
  `clip_contents`, нижняя обрезается; стартовый скролл — на **жёлтую (следующую)**
  карточку, чуть ниже, чтобы lvl-бейдж не обрезался сверху). Карточка
  (`_build_reward_card`): скруглённая, **жёлтая = следующий уровень** (к которому
  идёт скин), зелёная — получена, серая — заперта; на уровнях нового жира —
  **спрайт соответствующего жира покрупнее**,
  иконки монета(token)/доллар + «x{n}» с **чёрным stroke** (`_strong_label`),
  красный повёрнутый бейдж «lvl.N», аватар + «НОВЫЙ ЖИР!» на фат-уровнях,
  «Награда получена» на полученных.

Старые `_build_shop_card`/`_build_shop_section_header` оставлены, но больше не
используются. Резист-иконки — `_RESIST_TEX` (bochka/stone/glove/snake/fire/bomb/
molotov/shuriken). Кружки рисуются `_circle_tex()`.

## Реализация в забеге (2026-06-30)

**Кулдаун-кружки** (`scripts/skill_badges.gd`, слой строится HUD-ом в `_start_game`,
сносится на смерти): ряд круглых значков активного скина **под полоской ресурсов,
справа от контейнера с жиром** (якорь `_skill_badge_anchor` из `_build_ui`). Предмет
внутри нарисован **чуть крупнее кружка** (выступает за обводку). **Пока держишь палец
на кружке** — рядом (под ним) всплывает **подсказка** с названием и описанием навыка
(`_gui_input`/`_show_tip`, рамка в цвет кольца, `_clamp_tip` держит её на экране). —
**каждый предмет резиста = свой кружок** (резисты тикают параллельно), затем
активка, затем пассивка. На срабатывании кружок засвечивается, **засвет уходит по
кругу** (`draw_arc`, доля = remaining/total), по центру **число секунд** (белый шрифт,
тонкая 0.5-px чёрная обводка). Кулдаун кончился → значок **мигает 1 раз** и играет
звук (`assets/audio/skill_ready.mp3`, грузится если есть — добавить позже).

**Состояние кулдаунов** живёт в `normaldo.gd`: `_skill_cd` (`key -> [remaining, total]`,
ключи `resist:<tag>` / `active` / `passive:<id>`), API `start_skill_cd` /
`skill_cd_remaining` / `skill_cd_total` / `is_skill_ready`, тик в `_physics_process`.
Конфиг на забег — `_build_skin_runtime()` (из `SkinSkills`).

**Резисты** (`_handle_obstacle` / slowing-ветка): по тегу предмета (`_area_tag`:
группы fire/glove/snake/bum + текстура trash/stone + meta banana); если есть
**не на кулдауне** резист — предмет ломается без урона, его кружок уходит в КД,
звук `resist.mp3` + партиклы. Параллельно (бочка в КД — змея ещё работает).

**Активка по дабл-тапу** (`normaldo._input` → `_try_fire_ability(точка)`; окно
дабл-тапа **короткое** — `_DTAP_TIME` 0.20 c, `_DTAP_DIST` 55 px, чтобы кайты не
считались за дабл-тап). Если тапнуть
её **на кулдауне** — значок активки **пульсирует** красным (`pulse_deny`, сигнал
`active_denied`) и над Нормальдо всплывает слово **«Перезарядка»**. Снаряды —
`scripts/skill_projectile.gd` (летят по линии, сканируют группы, `hit_handler`
ломает/трансформирует/тормозит; `true` = снаряд гаснет, `false` = пробивает).
- **РЫГАЛИТИ** — крупное облако `smoke.png` в цвет (×2, **без вращения**, пульсирует
  размером), ломает **первый** задетый предмет **любого типа** (от пиццы до сюрикена —
  `_RYAG_HIT_GROUPS`, кроме мутагена/автомата) и **исчезает** (Очки — `_double_ryag`, два подряд).
- **Экспекто Патронум** (Гарри) — белая вспышка, чистит весь экран.
- **Бросок штурвала** (Пират) — `assets/skills/ship_wheel.png`, пробивает любые
  предметы насквозь и не ломается.
- **Королевский гамбит** (Джокер) — 3 карты `assets/skills/card.png`: средняя летит
  **прямо**, верхняя/нижняя — **по диагонали** (веером, `spread`); каждая ломает
  **первый** задетый предмет любого типа и исчезает (как Рыгалити).
- **Выстрел паутиной** (Спайдер) — комок **белых партиклов** (без облачка, след как
  у карт Джокера) уничтожает **первый** задетый предмет и исчезает. **3 заряда**:
  откат (`_active_charges`/`_active_max_charges`, поле `charges` в ability) стартует
  только после **третьего** выстрела и равен **50 c**. На бейдже — счётчик зарядов
  (пип снизу-справа), при израсходовании — обычная развёртка отката.
- **Трансформус** (Волшебник) — снаряд из **«магических» партиклов** (фиолетовый
  `0.70,0.40,1.0`, след как у карт Джокера, без облачка) превращает первый задетый
  предмет любого типа в пиццу/доллар (с сохранением его скорости) и исчезает. Звук
  полёта заряда — `magic_glitter.mp3`, превращения — `magic_poof.mp3` (`_play_oneshot`).

**Пассивки:** Бомж-жор (Дракула, резист бомжа → `_eat_pizza`×3); Сокровище (Пират,
50% пойманный доллар ×3 + поп `assets/skills/x3.png` + звук); Аэродинамика (Очки —
`_effective_fat_speed` режет штраф жира вдвое: 1.0/0.86/0.75/0.65) и Паучье чутьё
(Спайдер — `_move_speed_mult()` ×1.25 поверх любого жира); Второй
шанс (Гарри, `_harry_second_chance_ready` в `_take_hit`); Знаешь откуда эти шрамы?
(Джокер, `_scars_passive` → срабатывает при наборе жира **не чаще раза в 60 c**
(скрытый гейт `scars_recharge`), даёт 5 c неуязвимости: на голову
надевается **маска Кейси** `assets/items/casey_mask.png` (`_spawn_scars_mask`,
ребёнок `_sprite`), по истечении таймера **или при столкновении** с предметом
(one-hit shield) маска **отпадает** и падает вниз с вращением (`_drop_scars_mask`,
`_end_scars`). На время эффекта в ряду значков появляется **динамический синий кружок
с маской** и обратным отсчётом (`skill_badges.gd`, `dynamic`-бейдж — виден только пока
эффект идёт, потом исчезает). При этом **постоянный** кружок пассивки (★, ключ
`passive:scars_static`) висит **всё время** — маска-кружок это отдельный
динамический индикатор поверх него.
Старые легаси-уники (бессмертие Дракулы, колдовство Волшебника) **отключены**.

## Обзор

Скин — не просто косметика. По редкости скин несёт **резисты** (защиты с
кулдауном), **способность** (РЫГАЛИТИ или особый спелл) и иногда **пассивку**.

Прокачка скина открывает жировые состояния (Fat и Uber Fat). Каждый скин хранит
**собственный прогресс XP и уровень** — смена скина его не сбрасывает.

Подробнее о ценах — в [[Экономика]]. О жировых состояниях — в [[Система толщины]].

## Резисты

**Резист** — защита с кулдауном на конкретный предмет. Резист бочки даёт **сломать
бочку вместо удара об неё** (без урона), затем уходит на откат.

**UI:** сверху слева на каждый резист — **круглый значок с предметом внутри**. При
срабатывании кольцо **откатывается по кругу как идущие часы**, по центру — **число
секунд** до отката.

## Способности

- **РЫГАЛИТИ** (Classic/Common/Rare). **Дабл-тап** выпускает **облако** в сторону
  тапа (дымовая завеса ноги ниндзя, смодулированная в цвет). Облако **размером с
  обычный предмет**, летит **строго по линии Нормальдо → точка дабл-тапа** и ломает,
  во что попадёт. Откат: **10 c** (common/classic), **8 c** (rare, цвет уникальный).
- **Особый спелл** (Epic/Legendary) — вместо РЫГАЛИТИ, активный. Кд **8 c** (Epic),
  **20 c** (Legendary). У Эпиков спелл может быть вариантом РЫГАЛИТИ (Очки —
  «двойной рыгалити»).
- **Пассивка** — всегда активна. Есть не у всех (Дракула/Гарри/Пират/Спайдермен/
  Джокер — да; Волшебник — нет).
- Резист может покрывать **несколько предметов** одним кругом (cd общий).

**По редкости (фактически — см. таблицы скинов):**

| Редкость | Резисты | Способность | Пассивка |
|---|---|---|---|
| Classic | 0 | РЫГАЛИТИ 10 c (зелёный) | — |
| Common | 1 (10 c) | РЫГАЛИТИ 10 c (зелёный) | — |
| Rare | 1 (10 c) | РЫГАЛИТИ 8 c (уник. цвет) | — |
| Epic | 1–2 (8 c) | особый спелл / вариант РЫГАЛИТИ (8 c) | у части |
| Legendary | 1 резист на 2–3 предмета (8 c) | особый спелл (20 c) | у части |
