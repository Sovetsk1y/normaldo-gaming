# Прогрессия сложности

Ключевой дизайнерский вызов Normaldo: сложность должна нарастать так, чтобы игра оставалась **динамичной и читаемой** на любом этапе. Старый подход (ускорение) разрушал визуал. Новый строится на четырёх независимых осях.

## Проблема нулевой вовлечённости в начале

Первые 1–2 минуты — самые критичные для удержания игрока. Старый случайный спавнер давал:
- Редкие объекты → экран пустой → нечем заниматься
- Нет структуры → нет выбора → нет ощущения мастерства

**Решение:** с первой секунды спавнить [[Паттерны препятствий|паттерны T1]] — ресурсные линии. Игрок сразу видит «две полоски пицц вверху и внизу» и принимает решение. Вовлечённость мгновенная.

---

## Четыре оси прогрессии

### Ось 1: Инерция (lerp_weight)

`lerp_weight` определяется исключительно [[Система толщины|состоянием ожирения]] — никакого автоматического снижения по времени нет. Чем больше пиццы съел, тем тяжелее управление:

```
SKINNY   → weight ~0.22  (базовое, отзывчивое)
SLIM     → weight ~0.16
FAT      → weight ~0.11
UBER_FAT → weight ~0.08  (тяжело, нужно думать на 2 сек вперёд)
```

Это делает ожирение **единственным** рычагом изменения инерции — и целиком player-driven.

### Ось 2: Тиры паттернов (engagement-first)

[[Паттерны препятствий]] прогрессируют по **5 тирам вовлечённости**, не по скорости:

| Тир | Название | Ключевая механика | Угроза |
|-----|----------|-------------------|--------|
| T1 | Ресурсные линии | Выбор: верх или низ | Замедление (бананы) |
| T2 | Смешанные линии | Зигзаги, несколько дорожек | Редкие атаки |
| T3 | Фигуры | Читать рисунок на весь экран | Атакующие паттерны |
| T4 | Волны перчаток | Предсказать чередование волн | Летально, если не угадал позицию |
| T5 | Волны молотовов | Огневые зоны + ресурсы | Летально + сложные комбо |

Прогрессия внутри тира: простые → составные → волновые паттерны.

### Ось 3: Жир (player-driven)

[[Система толщины]] добавляет **игро-управляемую** сложность. Паттерновый спавн резко увеличивает количество собираемых ресурсов → жир набирается быстрее → управление становится тяжелее → игрок ощущает разницу состояний активнее. Игрок сам выбирает, насколько жадно есть.

### Ось 4: Фазовая скорость (без непрерывного ускорения)

Скорость предметов не нарастает непрерывно — она привязана к **фазам режима**:

- **Кампания** (7 мин до босса): 6 фаз с фиксированной скоростью каждая, см. [[Уровни/Кампания — алгоритм спавна]].
- **Бесконечный режим**: 10 фаз — первые 5 повторяют ramp кампании (Crescendo, 0–7 мин), затем серия "Безумие" (90 с каждая) добавляет модификаторы поверх скорости. См. [[Уровни/Бесконечный режим]].

В обоих режимах скорость и тиры паттернов прогрессируют **независимо** — скорость не определяет сложность паттерна.

---

## Взаимодействие осей

Четыре оси **независимы** — это важно. Примеры:
- Тонкий игрок на T4 паттернах: хорошее управление + сложные паттерны
- Жирный игрок на T2 паттернах: плохое управление + простые паттерны
- Быстрый тир скорости + простой T1 паттерн: всё летит быстро, но структура читается

```
engagement: T1 ──► T2 ──► T3 ──► T4 ──► T5   (паттерны)
weight:     ════════════════╗                  (определяется жиром)
speed:       ·──·──·──·     ╣                  (ступени)
fat:        ~~~~~~~~~~~~~~~~~╝                 (игрок)
```

---

## Почему это лучше старого подхода

| Старый | Новый |
|--------|-------|
| Скорость ↑ → визуал ломается | Скорость умеренная, паттерны сложнее |
| Первые минуты пусты | T1 линии захватывают с секунды 1 |
| Ресурсы разбросаны, сбор случаен | Ресурсные линии — структурированный сбор |
| Смерть = «всё слишком быстро» | Смерть = «не прочитал паттерн» |
| Один параметр | Четыре независимые оси |

## Кривая сложности по тирам паттернов

```
Вовлечённость
│
█████                                      ← T5 (молотов-волны)
│    █████                                 ← T4 (перчатки)
│         █████                            ← T3 (фигуры)
│              █████                       ← T2 (смешанные)
│                   █████                  ← T1 (линии, старт)
└─────────────────────────────────────────► Время
  0      1-2 мин    4-6 мин    8-10 мин+
```

Нет «плоского» старта — T1 сразу вовлекает, T5 — финальный вызов.

## Кампания — 7 минут до босса

Общая длина кампании: **7 минут (420 с)**. Скорость фаз нарастает, паттерны внутри каждой фазы выбираются случайно из взвешенного пула — это даёт разнообразие при сохранении нарастающей сложности.

| Фаза | Длина | Скорость | Паттерны (вес) |
|------|-------|----------|----------------|
| 0 | 60 с | 220 px/s | T1×7, T2×3 |
| 1 | 80 с | 242 px/s | T1×2, T2×5, T3×3 |
| 2 | 90 с | 264 px/s | T2×2, T3×4, T4/T5×4 |
| 3 | 90 с | 297 px/s | T2×1, T3×3, T4/T5×6 |
| 4 | 80 с | 330 px/s | T3×2, T4/T5×8 |
| pre-boss | 20 с | 330 px/s | только препятствия (no_pizza) |

Паттерн-тир для каждого спавна выбирается через `_campaign_pick_pat_tier()`: берётся взвешенный случайный выбор из `CAMPAIGN_PAT_WEIGHTS[phase]`.

## Сложность по уровням кампании

5 уровней с boss-fight на переходах:
- **Уровень 1** (NinjaFoot) — T1–T2 паттерны, обучение инерции и сбору линий
- **Уровень 2** (Leatherhead) — T2–T3, фигуры, первые атакующие паттерны
- **Уровень 3** — T3–T4, волны перчаток начинаются
- **Уровень 4** — T4–T5, сложные составные паттерны
- **Уровень 5** (ClubBoss) — T5, всё вместе, минимальный lerp_weight

---

## Параметр частоты спавна

Наряду с паттернами, **частота** появления объектов тоже растёт — умеренно. Цель: экран всегда насыщен, но хотя бы одна безопасная дорожка существует в любой момент.
