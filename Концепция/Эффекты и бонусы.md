# Эффекты и бонусы

Временные состояния, изменяющие поведение игры. С введением [[Принцип инерции (резинки)|инерционного управления]] некоторые эффекты приобретают новый смысл.

## Активные эффекты

| Эффект | Действие | Взаимодействие с инерцией |
|--------|----------|--------------------------|
| **slow** | lerp_weight × 0.5 | Сильно утяжеляет управление |
| **speedUp** | lerp_weight × 1.3 | Делает голову отзывчивее, почти прямое управление |
| **slowMo** | Скорость мира ÷ 2 | Больше времени на предсказание → «лёгкий режим» |
| **disorient** | Инвертирует направление тяги | С инерцией вдвойне дезориентирует — голова летит «не туда» с задержкой |
| **immortality** | Неуязвимость 10–15 сек | Можно жадно есть пиццу без риска смерти (жир всё равно растёт) |
| **immuneToSlowing** | Иммунитет к slow-предметам | Снимает ось снижения weight через предметы |
| **immuneToAttacking** | Иммунитет к урону | Защищает от потери жировых очков |

## Интересные взаимодействия

### slow + FAT
Оба снижают lerp_weight → комбо может сделать управление почти невозможным. Это пиковый момент сложности.

### speedUp + SKINNY
Управление становится почти прямым (как старая механика) → ненадолго возвращает ощущение «лёгкости», контраст к обычному управлению.

### slowMo
Мир замедляется → но инерция остаётся той же пропорционально. Игрок получает больше времени на предсказание — это «кнопка воздуха».

### disorient
С инерцией инверсия вдвойне сложна: игрок тянет вправо → голова уходит влево **с задержкой** → человек не может мгновенно перестроиться. Нужно «думать наоборот» заранее.

## Спутники (satellites)

При активных иммунитетах вокруг головы появляются объекты-спутники:
- **MagicHat** (immuneToSlowing) — вращается по орбите, блокирует slow-предметы
- **CaseyMask** (immuneToAttacking) — другая орбита, блокирует урон

Орбита описана кубической кривой Безье — визуально красиво и не слишком предсказуемо.

## Объекты, дающие эффекты

- **Hourglass / Cocktail / Beer** → slow
- **Energizer** → speedUp  
- **MagicHat item** → immuneToSlowing
- **CaseyMask item** → immortality
- **TV** → случайный эффект
- **Mutagen** → рандомное изменение состояния
