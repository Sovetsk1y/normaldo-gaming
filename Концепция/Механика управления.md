# Механика управления

## Старая механика (deprecated)

```
позиция_головы += delta_пальца × speed
```

Голова двигалась **относительно своего положения** по вектору движения пальца — куда и насколько быстро повёл палец, туда и с той же скоростью двинулась голова. Позиция пальца на экране не имела значения: можно было держать палец в правом углу и свайпнуть вниз — голова из любой точки поедет вниз. Управление было задачей «проведи пальцем вокруг препятствий» — задача решалась мгновенно, skill gap отсутствовал.

## Актуальная механика — Прямое перетаскивание + жир как множитель

```
drag → position += event.relative × FAT_SPEED_MULT[fat_state]
```

Голова движется **точно по вектору пальца**, с той же скоростью что палец, умноженной на коэффициент жира. Диван прикован к Нормальдо и движется вместе с ним. Пружина отсутствует.

### Коэффициенты по жиру

| Состояние | Множитель | Ощущение |
|-----------|-----------|----------|
| SKINNY    | 1.0       | 1:1 с пальцем |
| SLIM      | 0.72      | чуть медленнее |
| FAT       | 0.50      | заметно тяжелее |
| UBER_FAT  | 0.30      | инертная туша |

Дополнительно: дебаф замедления (`SLOW_MULTIPLIER = 0.30`) умножается поверх жирового коэффициента.

### Параметры

| Параметр | Диапазон | Эффект |
|----------|----------|--------|
| `lerp_weight` | 0.08–0.5 | «жёсткость резинки» |
| Высокий weight (0.4–0.5) | Начало игры | Отзывчиво, почти прямое |
| Средний weight (0.15–0.2) | Середина | Нужно планировать |
| Низкий weight (0.08–0.1) | Поздняя игра | Тяжёлая голова, предсказание на 2 сек |

### Ограничение прилипания (Stick Window)

Проблема чистого lerp: игрок может держать палец зажатым всё время, голова постепенно догоняет цель и дальше движется как при прямом управлении — инерция теряет смысл.

**Решение — временно́е окно прилипания:**

```
Tap → прилипание (MAX_STICK_TIME сек) → авто-отлип → дрейф к центру → следующий Tap
```

- `MAX_STICK_TIME = 2.5` сек — ручка баланса
- Пока окно активно: голова тянется к пальцу через lerp, палец можно двигать
- Истекло время (или отпустил палец) → прилипание снимается, голова дрейфует к центру
- Следующее касание сбрасывает таймер и открывает новое окно

**Шкала-дуга** рисуется вокруг головы и истощается по часовой стрелке. Цвет переходит голубой → оранжевый — заметное, но ненавязчивое предупреждение.

Появление шкалы — двухэтапное:
1. Голова «долетела» до пальца (`distance_to(target) < 15px`) — триггер прибытия
2. Пауза 0.25 сек → шкала появляется быстрым фейдом (0.15 сек)

Это значит: при коротких кликах и быстрых маневрах шкала не мелькает. Она возникает только когда голова реально «приклеилась» к цели и начинает копить время прилипания. При отпускании пальца или авто-отлипе — скрывается мгновенно.

Это создаёт ритм: **касание — тяни джойстик — отлип — пауза — касание**. Навык игрока — эффективно использовать каждое окно.

**Звуки Stick Window:**
- Натяжение (`tension.mp3`) — играет пока `joy_delta > 10px` (джойстик вытянут)
- Щелчок (`snap.mp3`) — играет в момент авто-отлипа по истечении 2.5 сек

### Поведение без прилипания

Когда окно закрыто — голова дрейфует к центру с тем же `lerp_weight`, но с замедляющим множителем:

```
position = lerp(position, center, lerp_weight × 0.25)
```

Множитель 0.25 делает возврат плавнее активного движения, но **жир тормозит и его** — при UBER_FAT дрейф почти незаметен кадр к кадру. Центр — интуитивная «безопасная зона» равновесия.

## Инверсия управления

Эффект `disorient` (один из [[Эффекты и бонусы]]) инвертирует направление — голова тянется в сторону, противоположную пальцу. С инерцией это становится вдвойне дезориентирующим и интересным.

## Влияние [[Система толщины|жира]] на управление

```
lerp_weight = base_weight × fat_multiplier

fat_multiplier:
  SKINNY:   1.0
  SLIM:     0.72
  FAT:      0.5
  UBER_FAT: 0.36
```

Жир не просто замедляет — он делает управление «тяжелее», требуя более раннего предсказания.
