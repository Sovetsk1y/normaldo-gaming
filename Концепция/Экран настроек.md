# Экран настроек — UX-спека

Связано: [[UI — паттерны интерфейса]], [[Экран книги учителя]], [[Уведомления]].

Спека написана ДО переделки и служит для неё заданием. Реализация —
`scripts/settings_screen.gd`, вход — `hud._show_settings_modal()`.

## Зачем игрок сюда заходит

1. **Убавить звук** — самая частая причина, и она должна решаться за один тап.
2. **Разобраться с уведомлениями** — выключить надоевшие, оставить нужные.
3. **Сохранить код восстановления** или войти по нему на новом телефоне.
4. **Поменять имя и аватар**.

## Что было не так

| Проблема | Следствие |
|---|---|
| Подэкран ЗАМЕНЯЕТ родителя: `root.queue_free()` → открыть уведомления | Закрыл уведомления — оказался в главном меню, а не обратно в настройках. Кнопки «назад» нет ни одной |
| Четыре окна с четырьмя разными шапками: X справа, X справа, «Отмена/Восстановить», «Отмена/Сохранить» | Флоу не читается как один раздел |
| Имя правится карандашом в меню, аватар — тапом по аватару в меню, код восстановления — в настройках | Профиль разбросан по трём местам, и ни одно не называется «профиль» |
| Панель 420 px на альбомном экране 960 | Узкая колонка со скроллом, слева и справа пусто. Настройки не влезают, хотя пунктов всего шесть |
| Уведомления: 8 переключателей + тихие часы в той же колонке | Обрезаны по нижнему краю, тихие часы за скроллом |
| Код восстановления замаскирован `*` и раскрывается только по «КОПИЯ» | Переписать его на бумажку нельзя — а это ровно то, что просит сделать пояснение под ним |
| Плоские прямоугольники с острыми углами и полоской сверху | Не совпадает ни с одним из переделанных экранов |

## Раскладка — разворот, как в книге учителя

Подэкранов больше нет: разделы слева, содержимое выбранного справа. Проблема
«закрыл подэкран и вылетел в меню» исчезает вместе с самими подэкранами.

```
┌────────────────────────────────────────────────────────────────────┐
│ ←            НАСТРОЙКИ                            12400$    83⊙    │
├──────────────────┬─────────────────────────────────────────────────┤
│ ▸ ЗВУК           │  ЗВУК                                           │
│   УВЕДОМЛЕНИЯ    │  Звуки              ▓▓▓▓▓▓▓░░░           70 %   │
│   ПРОФИЛЬ        │  Музыка             ▓▓▓▓░░░░░░           40 %   │
│   АККАУНТ        │                                                 │
│                  │                                                 │
│                  │                                                 │
│            v1.0.3│                                                 │
└──────────────────┴─────────────────────────────────────────────────┘
```

**Разделы:**

* **ЗВУК** — две полосы громкости с числом процентов.
* **УВЕДОМЛЕНИЯ** — общий выключатель, категории, тихие часы. Категорий восемь,
  поэтому правая страница здесь прокручивается внутри себя; всё остальное
  помещается целиком.
* **ПРОФИЛЬ** — аватар (тап открывает выбор), имя и кнопка «ИЗМЕНИТЬ ИМЯ».
  Собран в одном месте, а не разбросан по шапке меню.
* **АККАУНТ** — код восстановления **открытым текстом** (его и надо переписать),
  кнопка «КОПИРОВАТЬ», пояснение и «ВОССТАНОВИТЬ АККАУНТ».

Строка версии стоит внизу корешка — она нужна раз в жизни, при письме в
поддержку, и не должна занимать место в содержимом.

**Два настоящих диалога остаются модалками поверх экрана**: «изменить имя» и
«восстановить аккаунт». Это операции с подтверждением, у них есть «Отмена», и
после закрытия игрок возвращается **в настройки**, а не в меню.

## Состояния переключателя

| Состояние | Вид |
|---|---|
| Включено | залитая пилюля, кружок справа, подпись `ВКЛ` |
| Выключено | контурная пилюля, кружок слева, подпись `ВЫКЛ`, строка приглушена |

Положение кружка, заливка и слово — три признака на одно состояние; цвет из них
только один.

Когда общий выключатель выключен, категории гаснут и не нажимаются: щёлкать по
ним бессмысленно, а притворяться рабочими — врать.

## Доступность

1. Состояние переключателя — словом и положением кружка, не только цветом.
2. Громкость — числом процентов, а не только длиной полосы.
3. Из любого диалога есть путь назад в настройки, а не только «закрыть всё».
4. Ничего важного за скроллом: скроллится только список категорий уведомлений,
   и он один такой.

## Проверка

`dev/smoke_settings.gd`: экран собирается, корешок и страница не наезжают и не
выходят за края; переключаются все четыре раздела и каждый строит своё
содержимое; ползунок громкости пишет в `SaveData` и показывает то же число;
общий выключатель уведомлений гасит категории; переключатель категории
переживает пересборку страницы; код восстановления показан целиком; версия на
месте. Кадры снимает `dev/shot_settings.gd` (аргумент — раздел).
